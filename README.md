## About

I build **AI-native products and software systems end to end** — product scope, architecture, APIs, data and state, agent behavior, testing, and deployment.

My strongest work sits at the boundary between **probabilistic models and deterministic software**: structured outputs, tool use, retries, fallbacks, policy gates, idempotency, signed webhooks, evidence grounding, and failure-mode testing.

I use **Claude Code, Codex, and Cursor** as primary development tools for implementation, debugging, refactoring, repository exploration, and test generation. I still own the architecture and manually review the parts that cross trust, state, security, and execution boundaries before shipping.

**Current focus:** applied AI · agent systems · AI product engineering · fintech/payments · reliable LLM workflows

## How I Build

```text
Ambiguous product problem
        ↓
Define state, trust boundaries, and failure cases
        ↓
Use AI coding agents to implement and iterate quickly
        ↓
Review critical execution paths manually
        ↓
Add structured outputs / validation / retries / fallbacks
        ↓
Test adversarial and failure scenarios
        ↓
Deploy, exercise the real workflow, inspect what breaks
```

I prefer using the LLM for **ambiguity, language, planning, and interpretation**, while deterministic software owns **permissions, state transitions, validation, and high-consequence execution**.
