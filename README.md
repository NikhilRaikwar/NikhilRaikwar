`Solidity` `React` `USDC` `Arc/EVM`

**[Aegis](https://github.com/NikhilRaikwar/Aegis)** — [live ↗](https://aegis.nikhilraikwar.me/)

`Sui Move` `Next.js` `DeepBook`

**[Gavel](https://github.com/NikhilRaikwar/Gavel)** — [live ↗](https://gavel-nine.vercel.app/)
Autonomous on-chain escrow dispute resolution — research, validation, skeptic, and judge stages operate on public evidence with callback validation and retry paths.
`Solidity` `OpenAI` `Somnia`

**[RiskShield](https://github.com/NikhilRaikwar/riskshield-v4-hook)** — [live ↗](https://riskshield.vercel.app/)
Uniswap v4 impermanent-loss insurance hook — tranche-based, with senior LP protection and dynamic swap premiums. Built through Atrium Academy x Uniswap Foundation Hook Incubator, Cohort 9.
`Solidity` `Uniswap v4`

**[AgentOS](https://github.com/NikhilRaikwar/AgentOS)** — [live ↗](https://agentos.nikhilraikwar.me/)

`TypeScript` `ENS` `Uniswap V3`
